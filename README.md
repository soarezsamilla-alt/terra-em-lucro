# Terra em Lucro

A página deve ser otimizada para conversão, mobile-first, com visual limpo, cores terrosas/verdes (tema rural), tipografia forte em bold para headlines e CTAs em destaque (botão verde ou laranja, alto contraste).

Observações técnicas para o Lovable
Mobile-first, responsivo, carregamento rápido
Botões de CTA devem ser sticky/fixos no rodapé da tela em mobile, sempre visíveis
Cores: paleta terrosa (marrom, verde, laranja queimado), fundo predominantemente branco/bege claro
Tipografia: sans-serif bold para headlines, legível em qualquer tamanho de tela
Todos os preços e contadores devem estar em variáveis fáceis de editar depois
Se possível, adicionar popup de exit-intent (aparece quando o usuário tenta sair da página) oferecendo um cupom ou oferta intermediária — pode ser deixado como estrutura pronta para configurar depois
